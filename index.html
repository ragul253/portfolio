01 / Endpoint securityCISO-approved report

Windows 11 workstation hardening

A reusable security baseline for a UniFi Protect CCTV workstation, connecting technical controls with practical validation and maintenance.

BitLocker TPM+PINAppLockerLGPO / secedit
Read the project notes

The work. Hardened a Windows 11 Pro workstation using Secure Boot, least privilege, application allowlisting, USB restrictions, kiosk controls, firewall rules and audit logging.

The deliverable. A reusable configuration baseline, validation guidance and a CISO-reviewed and approved hardening report mapping controls to CIS Windows 11, NIST SP 800-53, ISO/IEC 27001 Annex A and ACSC Essential Eight.

The lesson. A baseline needs repeatable checks and a workable maintenance process, as well as secure settings.

The work. Built an initial segmentation lab in GNS3 and applied the approach in a separate Proxmox lab. Configured pfSense firewall rules and network segmentation.

The analysis. Reviewed security-event logs in ELK/Kibana and validated Snort IDS alerts against observed network behaviour.

03 / ICS & OT securityMaster’s thesis · 1.3

Context-aware incident prioritisation

A Purdue/PERA-based decision-support prototype that explores why equal-severity events can require different operational priorities.

Python / FlaskOpenPLCMQTTGrafana
Read the project notes

The build. A simulated ICS/OT lab combining Python, OpenPLC, Modbus/TCP, MQTT, Node-RED, InfluxDB and Grafana.

Simulation→MQTT→Node-RED→InfluxDB→Grafana

The evaluation. Four controlled scenarios—high temperature, tank overflow, pump-status manipulation and MQTT broker failure—combined severity, architectural layer, asset criticality and operational context into explainable priorities.

The boundary. A laboratory decision-support prototype with human-led response. Weights and thresholds were prototype assumptions requiring calibration before production use.
